# Teacher guide: advanced automotive systems

## Audience and preparation

Designed for advanced secondary, undergraduate or technical students with algebra, units, force balance and rotational mechanics. Use the demonstrator as a visual aid, not a substitute for schematics, verified component drawings or laboratory measurements.

Before class: run the checks; inspect the views; disable unwanted audio; explain fictional figures; provide static/text alternatives. Students must know which quantities are observations, supplied assumptions, computed outputs and validated measurements.

## Suggested six-session sequence

| Topic                       | Visual prompt                                         | Scientific task                                                                     | Boundary to state aloud                                                         |
| --------------------------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Bodywork and packaging      | Side/top views; canopy, arches and intake pods        | Annotate clearance, visibility, intake/cooling hypotheses and service access        | Geometry is approximate; apparent intakes do not prove flow paths               |
| Engine and power            | Engine-deck hotspot; controlled RPM/audio interaction | Derive `P=Tω`; compare operating points and torque curves                           | No cylinder animation or calibrated engine map; pitch is not torque measurement |
| Transmission and driveline  | Heritage RWD vs concept AWD description               | Map engine → clutch/gearbox → final drive → driven tires; compute ratios and losses | Gearbox and differential internals are not rendered                             |
| Chassis and dynamics        | Wheel locations and overall layout                    | Draw free-body diagram; compute axle loads and acceleration transfer                | No load-bearing chassis or suspension geometry is validated                     |
| Aerodynamics and cooling    | Rear bridge, concept canards and diffuser             | Analyze quadratic drag and power scaling; discuss downforce/drag trade-offs         | Spoiler appearance does not determine coefficients; no CFD exists               |
| Hybrid systems and critique | Specs comparison and silent mode                      | Distinguish component peaks from simultaneous system output; audit evidence         | Silent mode stops sound, not an energy-flow simulation                          |

Allow roughly 60–90 minutes per session, adjusted to the curriculum. Each session should include prediction, inspection, calculation, sensitivity analysis and discussion of limitations.

## Example 75-minute class

- 0–10 min: pre-question and validity legend.
- 10–20 min: guided side/rear/top observation; distinguish inference from observation.
- 20–40 min: paired SI calculation from the exercise sheet.
- 40–55 min: vary one input; predict before calculating.
- 55–65 min: critique an attractive but unsupported engineering claim.
- 65–75 min: transfer question and exit ticket describing one model limitation.

## Assessment rubric

Score each dimension 0–3 (not attempted, emerging, competent, justified):

1. Correct system relationships and component vocabulary.
2. Equation selection and consistent SI units.
3. Numerical reasoning and sensitivity explanation.
4. Explicit assumptions and limits of inference.
5. Transfer to a new operating condition.

A polished diagram alone earns no accuracy credit. This rubric is a proposed teaching aid, not a validated research instrument. Research use requires piloting, inter-rater agreement and the study protocol.
