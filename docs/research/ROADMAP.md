# Research roadmap

The following are proposed milestones, not existing functionality or release promises.

| Stage                   | Deliverable                                                              | Acceptance gate                                                                   |
| ----------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| 0 — Baseline            | Procedural showcase, SI teaching models, provenance, tests               | Build and checks pass; limitations visible                                        |
| 1 — Component pedagogy  | Labeled engine, transmission, chassis and suspension teaching assemblies | Mechanical expert review; consistent naming and units; keyboard-accessible labels |
| 2 — Inspection tools    | Cutaway, exploded views, isolation and transparent overlays              | Correct assembly transforms; labels do not imply hidden components exist          |
| 3 — Linked calculations | Teacher-editable parameters and equation-linked diagrams                 | Analytical state separated from fictional specifications; unit/invariant tests    |
| 4 — Calibration         | Measured geometry and approved engine/drivetrain/aero datasets           | Rights verified; uncertainties and calibration domain documented                  |
| 5 — Validation          | Physical benchmarks and classroom pilot                                  | Independent engineering review; ethics approval and pre-registered outcomes       |
| 6 — Dissemination       | Reusable lessons, accessible alternatives and study report               | Reproducible analysis; negative findings and limitations included                 |

Prioritize instructional clarity over new cinematic effects. Do not call the prototype a digital twin until a measured, synchronized and validated relationship to a physical system is established.
